# Official Agency Agents Engineering Council

When `/agency-council` is invoked, address the prompt by passing it through the official Agency Agents personas in sequential order:

1. **System Architect** (`software-architect.md`): System topology, data flow, and interface contracts.
2. **Backend Developer** (`backend-developer.md`): Server-side implementation, database logic, and API endpoints.
3. **Frontend Developer** (`frontend-developer.md`): UI components, state management, and user interaction.
4. **Security Engineer** (`security-engineer.md`): Threat modeling, input validation, and auth integrity.
5. **Reality Checker** (`reality-checker.md`): Critical verification, edge-case testing, and production sanity check.
