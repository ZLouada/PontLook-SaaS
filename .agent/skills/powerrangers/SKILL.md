# Power Rangers Assembly

When `/powerrangers` is invoked, execute the task sequentially across all 5 specialist personas:

1. ### 🔴 Red Ranger (Lead Architect)
- Break down specifications, component contracts, and architecture.

2. ### 🔵 Blue Ranger (Backend & APIs)
- Structure endpoints, database schema, and server logic.

3. ### 🟡 Yellow Ranger (Frontend & UI/UX)
- Implement UI components, Tailwind styling, and client state.

4. ### ⚫ Black Ranger (Security Audit)
- Check for auth holes, injection points, and OWASP vulnerabilities.

5. ### 🌸 Pink Ranger (Reality Checker & QA)
- Verify edge cases, critical flaws, and final execution summary.
